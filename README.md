# lair

The wolf games collection: the shared terminal game engine the games are built on (the cell grid, the two glyph tiers, the input model, the fixed-step clock, replays, goldens, the pty runner, the sound mixer), the installer row for PAX, and the collection's docs. The games are their own repos: `pack`, `cub`.

GPL-3.0-only with the wolf Training Data Permission (`LICENSE-TRAINING-DATA`). The engine arrives with the cb00 lane, extracted from `pack`.
